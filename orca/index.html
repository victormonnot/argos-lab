Planar disks · exact peer sensing · instantaneous velocity changes
Algorithm and variant
ORCA / reciprocal disk agents

Finite-horizon velocity half-planes with equal pairwise responsibility. Choose the feasible velocity nearest the goal preference inside a speed disk.

Decision architecture
Decentralized, leaderless

Each agent decides from its own goal and current peer positions, velocities and radii. Peers' goals and future commands are not inputs.

Timing and communication
Synchronous, discrete-time

All commands use the same pre-step snapshot. Perfect all-peer sensing; no messages, radio topology, delays or packet loss are simulated.

Execution and evaluator
One browser / planar kinematics

Disk agents change velocity instantly. The evaluator checks swept pair clearance and arrival. The 3D quadrotors share a fixed 1.15 m display height; ground disks keep the modeled collision radius. There is no vertical avoidance or flight physics.

Scope: local collision avoidance with assigned goals, no obstacles or global path planner. “Optimal” means nearest feasible velocity for this step; it does not mean a globally shortest route or guaranteed mission completion.

Change one assumption.
Watch the encounter.

Compare the rule, the look-ahead, the geometry and the information available.

01 / Compare the rules

Same crossing. Three decisions.

ORCA constrains the next velocity. APF combines attraction and repulsion. Direct motion follows the goal. Compare both clearance and arrival, using the same starts and goals.

02 / Look ahead

How early should an agent yield?

Shorten the prediction horizon from 2 s to 0.5 s. Watch the chosen velocity and the permitted region change. The sensing and the 0.05 s integration step stay the same.

03 / Test symmetry

Separated. Still unfinished.

Put two agents face to face with exactly symmetric goals. Run the full 40 s window, then compare their remaining goal distances with their physical separation.

04 / Remove peer observations

The neighbors are still there.

Keep the crossing, but remove every peer observation. The agents can still see their own goals. An unconstrained command can look feasible and still lead to contact.

Every case starts paused. The five reference cases use a 2 s horizon; the look-ahead exercise uses 0.5 s. These are deterministic browser simulations, not recorded flights or a general ranking of the methods.

Read the rule, assumptions & source +

For each pair, a finite-horizon velocity obstacle describes relative velocities that would bring the disks into contact. ORCA splits the required correction equally and builds one admissible half-plane per observed neighbor.

01 / Constrain · for each peer

qᵢⱼ = vᵢ + ½uᵢⱼ
Hᵢⱼ = { v : nᵢⱼ · (v − qᵢⱼ) ≥ 0 }

Correction to the relative-velocity obstacle boundary and the admissible side's normal.
½ / equal responsibility
Each cooperating peer takes half the pairwise correction from the same snapshot.
τ / prediction horizon
Look-ahead used to construct pair constraints. Peers recompute their velocities every step.

A local optimum

“Optimal” means nearest feasible velocity for this step. It does not promise the shortest route or eventual arrival. APF instead combines attraction and repulsion before capping speed.

A small geometric margin

Physical disks have a 0.30 m radius. ORCA adds 0.01 m per disk when constructing constraints. The evaluator measures the physical gap throughout each 0.05 s movement interval.

When no velocity fits

If the constraints and speed limit have no feasible intersection, the model commands zero and flags the decision as infeasible. This fallback is not a safety guarantee; none of the five reference runs needs it.

Sensing and reciprocity

The rule assumes exact peer state and compatible decisions. Missing observations remove constraints without removing the physical neighbors. The model has no messages, communication delays or uncooperative peers.

Primary method: van den Berg, Guy, Lin and Manocha — Optimal Reciprocal Collision Avoidance. This page implements a small educational variant, not an official RVO2 binding.

This model has circular footprints, instantaneous velocity changes and no static obstacles, acceleration limits or noisy localization. Symmetric agents may remain separated without reaching their goals within the budget. No physical safety claim, flight controller or live mission is inferred.
